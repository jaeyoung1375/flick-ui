## 갱신 규칙
* 라이브러리 버전은 `package.json`이 정본 — 이 문서는 사본이다. 어긋나면 `package.json`을 신뢰하고 이 문서를 고친다.
* 새 의존성 추가 시 이 문서에도 한 줄 추가한다. 실제로 쓰이지 않는 의존성을 발견하면 추측으로 지우지 말고 [`../12_known_issues/jobmoa-ui-known-issues.md`](../12_known_issues/jobmoa-ui-known-issues.md)에 먼저 기록한다.
