# 온보딩 – 남은 작업

현재 온보딩은 참고 디자인(플랜핏) 24개 화면 중 앞부분 14개 질문 + 마지막 요약 화면만 구현한 축약 버전입니다.
아래는 참고 디자인에는 있지만 이번 구현 범위에서 제외한 화면들입니다. 필요해지면 이 목록 기준으로 추가하면 됩니다.

## 제외된 질문 화면

- 집중하고 싶은 부위 중요도순 선택 (다중 선택, 2개 이상)
- 불편한 부위 선택 (없음/목/어깨/허리/팔꿈치) + 분기 질문
  - 어깨 선택 시: 팔을 어느 방향으로 움직일 때 불편한지
  - 손목 선택 시: 어떤 동작에서 불편한지
- 원하는 플랜 기간 선택 (6주/8주/12주/맞춤)
- 목표 체중 달성 예측 그래프
- 언제부터 운동할 예정인지 (지금/내일/3일 안/다음 주)
- "맞춤 플랜 구성중" 로딩 화면 + 운동 난이도 추가 질문
- 플랜핏(=Motive)을 어떻게 알게 됐는지 (유입 경로) + 검색 키워드 분기

## Step15 요약 화면

`Step15Page.tsx`의 통계 카드 항목은 이제 전부 실제 수집된 값입니다.
불편한 부위 / 운동 난이도는 질문 자체가 없어서 요약 카드에서도 제외되어 있습니다.

## 온보딩 완료 후 이동

지금은 완료 시 `/`(랜딩)로 이동합니다. 참고 디자인상 실제로는 운동 홈 대시보드("메인.jpg" — DAY 1 운동 카드, 헬스장/장비 등록,
하단 5탭 네비 등)로 이동해야 하는데, 이 대시보드 자체가 아직 없어서 별도 작업으로 남겨둡니다.

## 헬스장 검색 (Step8)

지금은 목데이터 4곳을 하드코딩해 이름으로만 필터링합니다. 실제 위치 기반 검색/거리 계산은 아직 없습니다.

- 카카오 로컬 API(키워드/카테고리 장소 검색)로 대체 예정. 상호명, 주소, 좌표(위도/경도)를 받아와 실제 헬스장 검색 및 거리 계산에 사용.
- 백엔드에 `GYMS` 테이블 신설 필요 (현재 `gymId`는 온보딩 스토어에만 존재, DB 저장처는 미정).
  - 카카오맵 장소 ID를 외부 참조키로 저장해두면 추후 동기화에 유리.
